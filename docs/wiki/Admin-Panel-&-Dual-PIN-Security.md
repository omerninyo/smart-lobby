# 🔐 Admin Panel & Dual-PIN Security

The admin dashboard (`admin.html`) is mobile-optimized and features role-based access control.

---

## 👥 Access Roles & PIN Codes

| Role | Default Template PIN | Visible Tabs | Description |
| :--- | :---: | :---: | :--- |
| **👤 Committee Member** | `1111` | 📢 Notices, 📻 Radio | Simplified mode for non-technical members. Hides all complex settings. |
| **🔑 Master Admin** | `1234` | All 6 Tabs | Full control over display calibration, contacts, security PINs, and cloud sync. |

---

## 📢 Notice Board Features
* **Priority Styling:** Mark notices as urgent for highlighted flashing red badges.
* **Vertical Split Layout (3:4):** 46% visual flyer + 54% typography.
* **Curated Image Picker:** Built-in modal gallery categorized by topic.
* **Auto-Expiration:** Set auto-expire dates after which notices automatically disappear.
