# 🌍 Deployment & Customization Guide

Launch a smart lobby board for your building in 3 minutes using GitHub Pages:

1. **Fork or Use Template:** Click **'Use this template'** on the main repository.
2. **Configure Building Details:** Edit `data/settings.json` with your building name, city, and GPS coordinates.
3. **Enable GitHub Pages:** Go to **Settings ➡️ Pages** ➡️ Select **Deploy from a branch (main)**.
4. **Setup Complete!** Your building dashboard is immediately live.
