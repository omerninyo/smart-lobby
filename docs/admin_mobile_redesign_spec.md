# מפרט הנדסי וארכיטקטורת עיצוב: פאנל ניהול Mobile-First (Admin SaaS v2)

מסמך זה מגדיר את הארכיטקטורה החזותית והממשקית האלטרנטיבית לפאנל הניהול (`admin.html`), בהתאם לעקרונות האיפוק החזותי בסעיף 7 בחוקי הפרויקט, תוך התמקדות בארגונומיה סלולרית מקסימלית (Mobile-First Thumb-Zone Architecture).

---

## 1. ניתוח הפערים בממשק הקיים מול שימוש במובייל

| רכיב בממשק | מצב קיים (`admin.html`) | בעיה עיקרית במובייל | פתרון מוצע ב-v2 |
| :--- | :--- | :--- | :--- |
| **שורת ניווט (Navigation)** | טאבים אופקיים עליונים בגלילה (`overflow-x-auto`) | רחוק מהישג היד של האגודל; רק 2-3 טאבים גלויים; גלילה מציקה | **Bottom Tab Bar (סרגל תחתון קבוע 5 טאבים)** + כפתור FAB מרכזי |
| **כותרת עליונה (Header)** | 6 כפתורים דחוסים (ענן, רדיו, Lite, רענון, צפייה, יציאה) | צפיפות יתר במסכים צרים (< 380px); גלישות שורה שוברות את העימוד | **Minimalist App Bar** הכולל סטטוס ענן חי, כפתור רדיו מהיר, רענון מסך ותפריט 3 נקודות |
| **טופס הוספת/עריכת הודעה** | תיבת טופס המוזרקת למרכז הדף ודוחקת את התוכן | דורשת גלילה ארוכה; קוטעת את רצף העבודה; אין שמירה קבועה במסך | **Native Bottom Sheet (מגירה תחתונה)** עם גלילה פנימית וכפתור שמירה מוצמד |
| **ניהול תמונות בהודעות** | חלונות מודאל מרובי שכבות שאינם מותאמים למגע | קושי בבחירת תמונה מהטלפון או גלילה במאגר תמונות | **מגירת גלריה סלולרית (Sub-Sheet) + העלאה ישירה מהמצלמה + כפתורי Presets** |
| **שפה גרפית ואייקונים** | עשרות אמוג'ים צבעוניים על כפתורים וטאבים (`🏢`, `📻`, `⚡`, `🔄`) | מראה חובבני ולא קוהרנטי; חוסר עקביות ברינדור בין iOS ל-Android | **Linear/Apple Style (Vector SVG)** - פלטת Slate/Zinc מאופקת ואייקוני רשת |
| **אנשי קשר ומעלית** | מפוזרים בתחתית עמודים או דורשים חיפוש | הגעה ארוכה ומסורבלת במקרה חירום | **טאב ייעודי "קשר"** עם כרטיסיית מוקד מעלית בולטת ומספרי חירום |
| **שדות בחירה (Select)** | תפריטי `<select>` רגילים (רדיו, מקור חדשות, מהירות) | תפריט מערכת הפעלה מגושם עם ריבוי לחיצות | **Segmented Controls וגריד כרטיסיות מגע** לבחירה מיידית בטאפ אחד |

## 2. מיפוי ארגונומי לאגודל (Thumb-Zone Ergonomics)

במכשירים מודרניים (6.1 אינץ' ומעלה), 80% מהשימוש מתבצע ביד אחת:

```text
┌────────────────────────────────────────┐
│  [🏢 הירדן 5]       [📻] [🔄] [•••]    │ <-- אזור קשה להגעה (מידע וקיצורי חירום)
├────────────────────────────────────────┤
│  [כרטיסיית הודעה 1 (עם תמונה)]         │
│  [כרטיסיית הודעה 2 (טקסט)]             │ <-- אזור תצוגה וגלילה טבעית
│  [כרטיסיית הודעה 3 (פגת תוקף)]         │
├────────────────────────────────────────┤
│   [📢]    [🎨]     [ ➕ ]    [📞]   [📻]  │ <-- אזור האגודל הטבעי (פעולות וניווט)
│  הודעות  תצוגה   חדשה (FAB)  קשר   רדיו │
└────────────────────────────────────────┘
```

## 3. פלטת צבעים וטוקנים (Design Tokens)

בהתאם ל-`docs/design_spec.md`, פלטת הצבעים מבוססת על שילוב כהה עמוק (Monochromatic Dark Restraint):

* **Surface Background (Canvas):** `#0B0F19` (רקע עמוק מונע סנוור בלילה)
* **Surface Card (Card Level 1):** `#131C2E` (Slate 900 מובנה)
* **Surface Elevated (Bottom Sheet):** `#111A2E` (מופרד באמצעות צללים עמוקים וגבול עדין)
* **Border Color:** `rgba(255, 255, 255, 0.08)` (דק, 1px, חד ומקצועי)
* **Accent Primary:** `#2563EB` (Blue-600) / `#38BDF8` (Sky-400 לטקסט מודגש)
* **Status Success (חי/מחובר/מוצג):** `#10B981` (Emerald-500)
* **Status Warning (פג תוקף):** `#F59E0B` (Amber-500)
* **Status Danger (דחוף/מחיקה):** `#EF4444` (Rose-500)

## 4. רכיבי המפתח בממשק החדש (Components Breakdown)

### 1. כותרת עליונה חכמה (Top Bar)
- גובה קבוע 56px עם `backdrop-filter: blur(18px)`.
- מציגה שם בניין מקוצר + אינדיקטור פעימה ירוק (סנכרון ענן פעיל).
- כפתור השתקה/הפעלת רדיו מהירה.
- כפתור רענון מסך מרחוק (Force Reload) למקרי חירום.
- תפריט 3 נקודות לפעולות מנהל נוספות ויציאה.

### 2. סרגל טאבים תחתון (Bottom Navigation Bar)
- גובה 64px + תמיכה ב-Safe Area של מכשירי אייפון ואנדרואיד (`pb-[env(safe-area-inset-bottom)]`).
- 5 טאבים ייעודיים עם אייקוני SVG חדים:
  1. **הודעות** (📢 הודעות ומודעות ועד)
  2. **תצוגה** (🎨 רקעים, מקור חדשות, טיקר ו-Lite Mode)
  3. **קשר** (📞 מוקד מעלית ומספרי חירום)
  4. **רדיו** (📻 10 תחנות ישראליות, שעות ווליום)
  5. **הגדרות** (⚙️ ניהול PINs, טלמטריה ובריאות המסך)
- במרכז הסרגל: **כפתור הוספה צף (Elevated Action Button)**:
  - כפתור כחול בולט של 48x48px עם סימן `+`.
  - פותח מיד את ה-Bottom Sheet ליצירת מודעה חדשה מכל מסך.

### 3. מנגנון ניהול תמונות להודעות (Image Management Workflow)
- **מגירת גלריית מאגר (Stock Gallery Bottom Sheet):**
  - תפריט קטגוריות: הכל, הודעות ועד, שבת ומועדים, נופים ואבסטרקט.
  - גריד 2 עמודות של כרטיסיות תמונה עם תג קטגוריה ושם.
  - בחירה בטאפ יחיד שמחזירה ישירות את התמונה לטופס ההודעה.
- **העלאה מהנייד / צילום במצלמה:**
  - כפתור ייעודי שמפעיל את בורר הקבצים והמצלמה של הטלפון.
  - המרה ודחיסה מקדימה ב-`FileReader` (DataURL) לתצוגה מיידית.
- **כפתורי בחירה מהירה (1-Click Presets):**
  - כפתורים לנושאים נפוצים: תחזוקה, ניקיון, שבת, חגיגי.
- **תיבת תצוגה מקדימה ומחיקה:**
  - תמונת Thumbnail בגודל 48x48px עם חיווי "מוכנה להצגה במסך".
  - כפתור "✕ הסר" שמאפס את התמונה בלחיצה אחת.

### 4. כרטיסיית מודעה מודרנית (Notice Card v2)
- גבול עדין (1px border), רדיוס 16px.
- שורה עליונה:
  - תג סטטוס קומפקטי: ירוק (`מוצגת במסך`), כתום מנוקד (`פג תוקף - הוסרה אוטומטית`).
  - כותרת מודגשת עם תמיכה ב-`truncate`.
  - תפריט כפתורים מהיר (עריכה / מחיקה) הנגיש בלחיצה אחת.
- גוף הכרטיסייה:
  - תמונת Thumbnail לצד הטקסט (אם צורפה תמונה).
- שורת תחתית:
  - תאריך ושעת תפוגה מדויקים (`15/09 20:00`).
  - חיווי מקור התמונה.

### 5. מגירה תחתונה לעריכה (Bottom Sheet Form)
- במקום מודאל שצף במרכז המסך, הטופס מחליק מתחתית המסך כלפי מעלה.
- פס גרירה (Drag Handle) בראש המגירה.
- כפתור שמירה גדול מוצמד לתחתית (Sticky Footer) שלא נעלם בעת פתיחת מקלדת המגע.
- שדות קלט עם מינימום 16px גודל גופן למניעת Auto-Zoom של דפדפני iOS.
