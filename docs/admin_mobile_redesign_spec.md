# מפרט הנדסי וארכיטקטורת עיצוב: פאנל ניהול Mobile-First (Admin SaaS v2)

מסמך זה מגדיר את הארכיטקטורה החזותית והממשקית האלטרנטיבית לפאנל הניהול (`admin.html`), בהתאם לעקרונות האיפוק החזותי בסעיף 7 בחוקי הפרויקט, תוך התמקדות בארגונומיה סלולרית מקסימלית (Mobile-First Thumb-Zone Architecture).

---

## 1. ניתוח הפערים בממשק הקיים מול שימוש במובייל

| רכיב בממשק | מצב קיים (`admin.html`) | בעיה עיקרית במובייל | פתרון מוצע ב-v2 |
| :--- | :--- | :--- | :--- |
| **שורת ניווט (Navigation)** | טאבים אופקיים עליונים בגלילה (`overflow-x-auto`) | רחוק מהישג היד של האגודל; רק 2-3 טאבים גלויים; גלילה מציקה | **Bottom Tab Bar (סרגל תחתון קבוע)** + כפתור FAB מרכזי להודעה חדשה |
| **כותרת עליונה (Header)** | 6 כפתורים דחוסים (ענן, רדיו, Lite, רענון, צפייה, יציאה) | צפיפות יתר במסכים צרים (< 380px); גלישות שורה שוברות את העימוד | **Minimalist App Bar** הכולל סטטוס חי + תפריט פעולות (Sheet / 3 Dots) |
| **טופס הוספת/עריכת הודעה** | תיבת טופס המוזרקת למרכז הדף ודוחקת את התוכן | דורשת גלילה ארוכה; קוטעת את רצף העבודה; אין שמירה קבועה במסך | **Native Bottom Sheet (מגירה תחתונה)** עם כפתורי שמירה/ביטול מוצמדים |
| **שפה גרפית ואייקונים** | עשרות אמוג'ים צבעוניים על כפתורים וטאבים (`🏢`, `📻`, `⚡`, `🔄`) | מראה חובבני ולא קוהרנטי; חוסר עקביות ברינדור בין iOS ל-Android | **Linear/Apple Style (Vector SVG)** - פלטת Slate/Zinc מאופקת ואייקוני Heroicons |
| **שדות בחירה (Select)** | תפריטי `<select>` רגילים (רדיו, מקור חדשות, מהירות) | תפריט מערכת הפעלה מגושם עם ריבוי לחיצות | **Segmented Controls** כפתורים מפוצלים לבחירה מיידית בנגיעה אחת |
| **גובה אלמנטים למגע** | חלק מהכפתורים בגובה 32px–36px | קושי בלחיצה מדויקת ביד אחת בהליכה | **תקן Apple HIG:** מינימום 44px–48px לכל אזור לחיץ |

## 2. מיפוי ארגונומי לאגודל (Thumb-Zone Ergonomics)

במכשירים מודרניים (6.1 אינץ' ומעלה), 80% מהשימוש מתבצע ביד אחת:

```text
┌────────────────────────────────────────┐
│  [🏢 הירדן 5]           [🟢] [•••]    │ <-- אזור קשה להגעה (מידע בלבד)
├────────────────────────────────────────┤
│                                        │
│  [כרטיסיית הודעה 1]                     │
│  [כרטיסיית הודעה 2]                     │ <-- אזור תצוגה וגלילה טבעית
│  [כרטיסיית הודעה 3]                     │
│                                        │
├────────────────────────────────────────┤
│   [📢]     [🎨]    [ ➕ ]   [📻]   [⚙️]  │ <-- אזור האגודל הטבעי (פעולות וניווט)
│  הודעות   תצוגה   חדשה    רדיו   הגדרות│
└────────────────────────────────────────┘
```

## 3. פלטת צבעים וטוקנים (Design Tokens)

בהתאם ל-`docs/design_spec.md`, פלטת הצבעים מבוססת על שילוב כהה עמוק (Monochromatic Dark Restraint):

* **Surface Background (Canvas):** `#090D16` (רקע עמוק מונע סנוור בלילה)
* **Surface Card (Card Level 1):** `#111827` (Slate 900 עם שקיפות עדינה)
* **Surface Elevated (Bottom Sheet & Modals):** `#161F30` (מופרד באמצעות צללים וגבולות עדינים)
* **Border Color:** `rgba(255, 255, 255, 0.08)` (דק, 1px, חד ומקצועי)
* **Accent Primary:** `#0284C7` (Sky-600) / `#38BDF8` (Sky-400 לטקסט מודגש)
* **Status Success (חי/מחובר):** `#10B981` (Emerald-500)
* **Status Warning (פג תוקף/מוסתר):** `#F59E0B` (Amber-500)
* **Status Danger (מחיקה):** `#EF4444` (Rose-500)

## 4. רכיבי המפתח בממשק החדש (Components Breakdown)

### 1. כותרת עליונה חכמה (Top Bar)
- גובה קבוע 56px עם `backdrop-filter: blur(12px)`.
- מציגה שם בניין מקוצר + אינדיקטור פעימה ירוק (סנכרון ענן פעיל).
- תפריט פעולות צדדי (3 נקודות) הפותח Quick Settings Sheet: רענון מסך הלובי, החלפת PIN, מצב Lite Mode וצפייה במסך.

### 2. סרגל טאבים תחתון (Bottom Navigation Bar)
- גובה 64px + תמיכה ב-Safe Area של מכשירי אייפון ואנדרואיד (`pb-[env(safe-area-inset-bottom)]`).
- 4 טאבים ייעודיים עם אייקוני SVG חדים:
  1. **הודעות** (Icon: Chat / Newspaper)
  2. **תצוגה** (Icon: Sliders / Layout)
  3. **רדיו** (Icon: Radio / Audio)
  4. **הגדרות** (Icon: Shield / Cog)
- במרכז הסרגל: **כפתור הוספה צף (Elevated Action Button)**:
  - כפתור כחול בולט של 48x48px עם סימן `+`.
  - פותח מיד את ה-Bottom Sheet ליצירת מודעה חדשה מכל מסך.

### 3. כרטיסיית מודעה מודרנית (Notice Card v2)
- גבול עדין (1px border), רדיוס 12px.
- שורה עליונה:
  - תג סטטוס קומפקטי: ירוק (`מוצגת`), כתום (`פג תוקף`), או אפור (`מוסתרת`).
  - כותרת מודגשת עם תמיכה ב-`line-clamp-1`.
  - תפריט כפתורים מהיר (עריכה / הסתרה / מחיקה) הנגיש בלחיצה אחת.
- שורת תחתית:
  - תאריך ושעת תפוגה מדויקים (`15/09 20:00`).
  - תג תמונה ממוזער (Thumbnail) אם צורפה תמונה.

### 4. מגירה תחתונה לעריכה (Bottom Sheet Form)
- במקום מודאל שצף במרכז המסך, הטופס מחליק מתחתית המסך כלפי מעלה.
- פס גרירה (Drag Handle) בראש המגירה.
- כפתור שמירה גדול מוצמד לתחתית (Sticky Footer) כדי שלא ייעלם בעת פתיחת מקלדת המגע.
- שדות קלט עם מינימום 16px גודל גופן כדי למנוע ממכשירי iPhone לבצע Auto-Zoom מעצבן.
